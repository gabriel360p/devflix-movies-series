## 📌 Sobre o projeto



O **DevFlix Movies & Series** é uma aplicação web desenvolvida para simular uma plataforma de catálogo de filmes e séries, oferecendo uma experiência semelhante aos serviços modernos de streaming.



O projeto tem como objetivo consumir dados externos, organizar informações de entretenimento e apresentar conteúdos de forma visualmente atrativa através de uma interface responsiva.



A aplicação foi desenvolvida utilizando conceitos importantes do desenvolvimento Front-end, como consumo de APIs, gerenciamento de estados, criação de componentes reutilizáveis e organização de interfaces dinâmicas.

## 🧠 Desafios enfrentados



Durante o desenvolvimento, alguns desafios importantes foram trabalhados:



### 🔄 Consumo de API externa



Um dos principais desafios foi trabalhar com dados externos, realizando requisições e tratando as informações recebidas para exibição correta na interface.



Foram considerados:



- carregamento dos dados;

- tratamento das respostas;

- organização das informações;

- experiência durante a navegação.



### 🧩 Componentização



Criar componentes reutilizáveis para evitar repetição de código e facilitar a expansão da aplicação.



### 📱 Responsividade



Garantir que a experiência de navegação permanecesse agradável em diferentes dispositivos, mantendo organização dos cards e conteúdos.



### 🎨 Experiência visual



Construir uma interface inspirada em plataformas de streaming, equilibrando informações, imagens e navegação.

## 💻 Como executar o projeto



Clone o repositório:



```bash
git clone https://github.com/gabriel360p/devmovies.git
```



Acesse a pasta:



```bash
cd devmovies
```



Instale as dependências:



```bash
npm install
```



Execute o projeto:



```bash
npm run dev
```



Acesse no navegador:



```
http://localhost:5173
```
